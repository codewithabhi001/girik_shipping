# GIRIK Shipping - Digital Maritime Bureau

![GIRIK Logo](https://img.shields.io/badge/GIRIK-Digital%20Maritime%20Bureau-0B2545?style=for-the-badge)

## 🚢 Overview

GIRIK Shipping is a modern, digital-first maritime certification platform that transforms how the shipping industry handles vessel compliance, surveys, and documentation. Our platform connects ship owners, surveyors, flag administrations, and port authorities through a unified, trusted system.

## ✨ Features

- **Digital Certification** - End-to-end digital workflow from survey request to certificate issuance
- **QR Verification** - Instant certificate authentication with unique QR codes
- **40+ Flag States** - Authorized by over 40 flag administrations worldwide
- **Global Surveyor Network** - 150+ expert surveyors across 120+ ports
- **Real-time Tracking** - Live status updates and notifications
- **Secure Platform** - AES-256 encryption and role-based access control

## 🛠️ Tech Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom design system
- **Build Tool**: Vite
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/codewithabhi001/girik_shipping.git

# Navigate to project directory
cd girik_shipping

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:3000`

### Build for Production

```bash
npm run build
```
